# 🛒 Проект: Тестирование платформы DemoShopping

В ходе учебного проекта я провел полный цикл функционального тестирования веб-приложения [intern.demoshopping.ru](https://intern.demoshopping.ru).

## Что было сделано:

- **[Анализ документации](https://docs.google.com/spreadsheets/d/1d9-W1loLULwZDmPY9KTxQIizGcCmWPT0exh2xjekW3I/edit?gid=0#gid=0)** — провел аудит требований и макетов на предмет полноты и непротиворечивости.
- **[Тест-дизайн](https://docs.google.com/spreadsheets/d/1NC9BjfiKWYYbkcD4JKNml7GEhDkKqkwIl8b8z8LC7i0/edit?gid=0#gid=0)** — сформировал стратегию тестирования, определив оптимальные уровни (Unit, Integration, System) и методы (Black Box, Gray Box, UI-testing) для данного продукта.

## Разработка документации:

- **[Чек-лист](https://docs.google.com/spreadsheets/d/1oqaWnxYJmig39JWRjX0CJl1LAXoiAMsgP_raC_5-kck/edit?pli=1&gid=1280288917#gid=1280288917)** — оптимизировал проверки для критических модулей: «Регистрация», «Авторизация» и «Каталог».
- **[Тест-кейсы](https://drive.google.com/file/d/1D37TNWuW4CO7MJ0_8NAkSTcc884QwkeO/view?usp=drive_link)** — спроектировал и реализовал тестовые сценарии в TMS **Test IT**.
- **[Баг-репорты](https://drive.google.com/drive/folders/1mAjRYdvcM15VT0cfsYES3q-N7zz-Zv_R)** — обеспечил жизненный цикл дефектов в **Jira**, подготовив детальные отчеты об обнаруженных ошибках.
